# surferCIAC

Proyecto de juego educativo de primer año USM que integra el motor de tres carriles de [DanielLin0516/SUBWAY-SURFERS](https://github.com/DanielLin0516/SUBWAY-SURFERS).

**Estado legal:** el proyecto original no tiene una licencia de reutilización declarada. No se copian aquí sus archivos de código ni sus modelos 3D. La integración local y su publicación requieren autorización del titular de ese contenido. El resto de archivos de este repositorio contienen únicamente la implementación propia de las preguntas, ranking y moderación.

La implementación del juego, la configuración y los pasos de instalación están documentados en este repositorio. Ningún puntaje o nombre de jugador se precarga.
